Για αυτή την έκδοση του χάρτη

Για πρόβλημα, ιδέα ή συνεργασία χρησιμοποίησε την ιδιωτική φόρμα. Πρόσθεσε προαιρετικά email για απάντηση και κράτησε τον αριθμό αναφοράς.

Στείλε μήνυμα στον διαχειριστή ↗

Για πρόβλημα: σημείωσε γραμμή, κατεύθυνση, στάση, ημερομηνία και ώρα Ελλάδας, τι περίμενες και τι εμφανίστηκε. Για integration: πρόσθεσε σύνδεσμο έργου και σύντομη περιγραφή. Μην στέλνεις passwords ή API keys.

Για το API του αρχικού έργου

Το backend ανήκει στο αρχικό έργο και έχει ξεχωριστό διαχειριστή. Για ερωτήσεις API ή integration μπορείς να ανοίξεις GitHub issue στο repository του. Τα issues είναι δημόσια και απαιτούν λογαριασμό GitHub.
